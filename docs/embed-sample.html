How a name becomes an address

Network notes, 24 November 2026

Every program that opens a connection starts with a name. Before any packet leaves the machine, the stub resolver checks the local hosts file and then asks the resolver configured in resolv.conf.

The resolver does the walking. On a cold cache it queries a root server, follows the referral to the TLD, and then to the zone that holds the record. Each step returns the next name to ask.

The answer is cached for its TTL, so the next lookup usually stops at the resolver. The full walk happens again only after the record expires or the cache is cleared.
