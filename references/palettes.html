Mint stays #46755c in every screen palette, so the pill keeps white text at 5.3:1. P0 prints the pill light grey with black text. The lowest text pair is 5.58:1 (D3 muted on card); the lowest accent edge is 4.17:1 (L2 accent on page background).

To ship a pair, copy the light row into ':root' and the dark row into the 'prefers-color-scheme: dark' block. Keep the seven token names unchanged.

Connectors and plain arrowheads use the muted token; the line token stays on card and tag borders.

Every block uses one geometry: main column 470 px at x=300, card pitch 108, one focus card and one accent connector. Only the color tokens change.
